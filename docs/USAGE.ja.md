# Songcut ユーザーガイド

## 概要

`Cut`は動画から歌唱区間を切り出すモードで、`Sub`は歌詞を動画へ合わせて字幕を作るモードです。
動画を読み込んだ後、画面上部の`Cut`または`Sub`を選ぶと用途を切り替えられます。

Cutでは検出した歌唱区間をセグメントとして確認し、タイトル、境界、書き出し対象を編集します。
波形とプレビューを使って、曲ごとの切り抜きとタイムスタンプを作成できます。

![Cut モードの編集画面](image/screenshot-cut.png)

Subでは歌詞を音声へ合わせ、複数の字幕タイムラインで文字、タイミング、表示位置を編集します。
字幕スタイルを設定すると、字幕付き動画とタイムライン別の字幕ファイルを書き出せます。

![Sub モードの編集画面](image/screenshot-sub.png)

## 共通操作

### 準備

起動時にFFmpegが見つからない場合は、次のコマンドでインストールしてSongcutを再起動してください。

```powershell
winget install Gyan.FFmpeg
```

YouTubeの動画を準備する場合は、`yt-dlp`とDenoをインストールしてから次のコマンドを実行します。

```powershell
winget install yt-dlp.yt-dlp
winget install DenoLand.Deno
yt-dlp --write-info-json --write-comments "<YouTube URL>"
```

`--write-info-json`と`--write-comments`を指定すると、Cutで概要欄や取得済みコメントのタイムスタンプをガイド候補として利用できます。

### 動画を読み込む

`読み込む`を押して動画ファイルを選ぶと、上側のプレビューと下側のタイムラインに動画が表示されます。

![動画の読み込みと解析](image/load-analyze.png)

波形は動画の読み込み後に準備され、準備できた部分からシークに使えます。
CutとSubはそれぞれ`設定 > Cut`または`設定 > Sub`の**波形表示**で`RMS`、`ピーク包絡`、`ピーク + RMS`、`対称ピーク`の4種類を選べます。

Opus音声の動画では、シークを速くするAACスクラッチ音声がバックグラウンドで準備されます。
通常再生と書き出しには元の動画が使われ、スクラッチ音声は設定の**スクラッチ音声プロキシを使用**で無効にできます。

### セグメントを調整する

タイムライン上の区間は左右のハンドルをドラッグして開始と終了を調整できます。
区間をダブルクリックすると**セグメント時刻**ダイアログが表示され、開始時刻と長さまたは終点を入力できます。

再生、境界の試聴、境界間の移動、ズームはCutとSubで共通です。
キーボード操作の一覧は[KEYBOARD_SHORTCUTS.md](KEYBOARD_SHORTCUTS.md)を参照してください。

![共通の再生・境界調整ツール](image/tools.png)

## Cut

Cutは配信や動画から曲ごとのクリップを作るためのモードです。
動画を読み込み、必要ならタイムスタンプコメントをガイド欄へ貼り付けてから`解析`を押すと、歌唱区間がセグメントとして表示されます。
動画と同名の`.info.json`がある場合は、動画概要欄や取得済みコメントのタイムスタンプを確認し、必要な候補だけをガイド欄へ適用できます。

解析結果のセグメントを選ぶと、タイトル、開始・終了、書き出し対象のチェックを編集できます。
`Segment`メニューでは、セグメントの追加、削除、開始時刻順の並べ替え、書き出し対象の一括選択を行えます。
タイムスタンプガイドを使う場合は、曲ではない配信開始、MC、宣伝、雑談、告知などの行を削除してから適用してください。

![Cut セグメントの編集箇所](image/edit-segment.png)

Cutの`Q`/`E`は最寄りの境界を設定した秒数だけ左右へ微調整し、`W`/`S`は前後のCutセグメントを選びます。
Cutの**振幅レンジ**は`設定 > Cut`にだけあり、標準表示と歌唱・MC強調を切り替えられます。

### Whisperで文字起こしする

新規プロジェクトでは、Cut解析後の自動文字起こしはオフです。
自動文字起こしを使う場合は`設定 > Cut`で有効にし、`設定 > AIモデル`でWhisperのモデル、言語、デバイスを選びます。

解析済みのセグメントは、`設定 > Cut`の**文字起こし／再実行**を押すと後から文字起こしできます。
モデルまたは言語を変更した後に同じボタンを押すと、設定に合わせて再文字起こしされます。

### Cutを書き出す

`書き出し`を押すと、チェックしたセグメントの動画クリップを書き出せます。
書き出し前の確認画面には実際のファイル名とクリップごとのスマートレンダリング予定が表示され、対応できない動画や区間は自動的に全体再エンコードへ切り替わります。
元動画と同名の子フォルダへまとめる設定を有効にすると、動画クリップと任意のタイムスタンプファイルを同じフォルダへ保存できます。

`TSを書き出す`を押すと、チェックした区間をタイムスタンプ形式でクリップボードへコピーできます。
`書き出し`メニューからは、タイムスタンプコメント、YouTubeチャプター、TSV/Excel、CSV、Audacityラベルも直接コピーできます。

## Sub

Subは歌詞をタイミング付き字幕として編集し、字幕付き動画を作るためのモードです。
上部の操作ボタンから解析や書き出しを始め、字幕タイムラインとスタイル設定で字幕を整えます。

![Sub モードの主な編集箇所](image/sub-overview.png)

### 歌詞を解析する

Subで動画を読み込んで`解析`を押すと、必要なモデルの準備後に`歌詞を貼り付け`ダイアログが表示されます。
初回は、選択した歌詞配置アルゴリズムに必要なモデルの準備が終わってからダイアログが表示され、`Songcut Standard`を選んだ場合はMMSも準備されます。

![歌詞の貼り付け](image/sub-lyrics.png)

歌詞を1行ずつ貼り付けてダイアログの`解析`を押すと、歌詞のタイミング解析が始まります。

![歌詞解析の進捗](image/sub-analysis.png)

解析が終わるとBPM、信頼度の統計、低信頼度として強調された行が表示されるので、内容を確認します。
タイムライン上の拍グリッドも確認し、拍検出が利用できない警告がある場合は境界を手動で調整してください。

### 文字・タイミング・タイムラインを編集する

歌詞ラベルをダブルクリックすると文字を編集でき、区間のハンドルをドラッグするとタイミングを調整できます。
区間をダブルクリックすると**セグメント時刻**ダイアログが表示され、開始時刻と長さまたは終点を編集できます。

`タイムライン`を押して9方向から字幕位置を選ぶと、字幕タイムラインが追加されます。
追加したタイムラインをクリックするとアクティブになり、最大3本まで作成できます。`W`/`S`はアクティブなタイムライン内の前後の区間を選びます。

`セグメント`を押すと、アクティブなタイムラインの選択位置へ4拍分の新しい字幕区間が追加されます。
ツールバーのごみ箱は選択中の字幕区間を削除し、タイムライン名の横にあるごみ箱はそのタイムラインを削除します。
Subの`Q`/`E`は選択した境界を前後の1/4拍へ移動します。

### スタイルを設定する

タイムラインの`Style`ボタンを押すと`字幕スタイル`ダイアログが表示されます。

![字幕スタイル](image/sub-style.png)

`保存スタイル`で保存済みプリセットを選んで`反映`を押すか、スタイル名を入力して`保存`を押すとプリセットを適用・保存できます。
`書体と色`ではフォント、文字色、背景色、縁色、太字、斜体を設定でき、`表示位置`では字幕の位置、サイズ、縁幅、影、左右余白、上下余白を設定できます。

`出力エフェクト`は書き出し時だけ適用され、編集中のプレビューには表示されません。

### 字幕を書き出す

`書き出し`を押して出力先を選ぶと、字幕付き動画とタイムライン別の字幕ファイルが作成されます。
字幕付き動画は`<動画名>-subtitled.mp4`で、各タイムラインは`<動画名>-sub-1.srt`、`<動画名>-sub-2.srt`のように出力されます。
各SRTには対応するスタイルファイル`<動画名>-sub-1.srt.style`が作成されます。

## 設定

設定ダイアログには`共通`、`Cut`、`Sub`、`AIモデル`の4タブがあります。

### 共通

共通タブではスクラッチ試聴時間、スクラッチ音声プロキシ、表示言語、FFmpegの確認を設定できます。
`Language / 言語`で`System default / システムの設定`、`English / 英語`、`Japanese / 日本語`を選ぶと、次回起動時から表示言語が切り替わります。

### Cut

Cutタブでは波形表示、振幅レンジ、歌唱解析デバイス、局所境界補正、自動Whisper文字起こし、出力ファイル名テンプレートを設定できます。
出力ファイル名テンプレートでは`{index}`、`{title}`、`{id}`、`{start}`、`{end}`を使えます。
新規プロジェクトのWhisper自動文字起こしはオフです。

### Sub

Subタブでは波形表示と歌詞配置アルゴリズム`Songcut Standard`または`Uta-Align`を設定できます。

### AIモデル

AIモデルタブのWhisper現行既定モデルは**Large v3 Turbo INT8 (OpenVINO)**です。
Whisperの言語とデバイスを選び、必要なモデルが未準備なら`Whisper モデルを準備`を押してください。
Subの解析では`Demucs`がボーカル分離に使われるため、必要なら`Demucs モデルを準備`を押します。
`MMS`は`Songcut Standard`の歌い出し補正でだけ使われ、`Uta-Align`では使われません。

## 保存と復旧

編集内容は動画の隣へ自動保存され、CutとSubでは別のサイドカーが使われます。
Cutのプロジェクトは`video.mp4.songcut`、Subのプロジェクトは`video.mp4.sub.songcut`に保存されます。
すぐに保存するには`Ctrl+S`または`File > Save Project Now`を使ってください。

異常終了後に復旧データがある場合は、次回起動時に`Recover`または`Discard`を選びます。
動画を移動または改名した場合は`File > Relink Source`で新しいファイルを指定してください。
