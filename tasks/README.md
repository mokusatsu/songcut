# Task brief運用

ルートの`tasks/`は、[作業タスクリスト](../docs/task-list.md)に登録された各タスクの詳細を保存します。

## ファイル規則

- ファイル名は`SCUT-NNN.md`とし、`task-list.md`のIDと一致させる。
- 一覧には要約だけを書き、実装判断と完了判定に必要な詳細は個別briefへ記録する。
- 過去タスクのIDやbriefは削除・再利用しない。実行しない場合も状態と理由を残す。

## 新規briefの必須項目

1. 目的
2. 変更範囲
3. 禁止事項
4. 完了条件
5. テスト方法
6. 停止条件
7. 実施証跡

完了条件は第三者が達成・未達を判断できる内容にし、実施証跡には実行コマンド、テスト件数、実環境確認、差分確認などを記録します。

SCUT-001〜024は旧一覧から移した履歴のため、同じ項目を箇条書き見出しで保持しています。SCUT-025以降と今後の新規briefは上記のMarkdown見出しを使います。
